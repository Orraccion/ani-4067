1/ A 72Hz:
    On a T = 1000/72 = 13,888 ~ 13,9ms
    Le temps qu'il reste pour le code est t = 13,9 - 8 = 5,9ms

2/ A 90Hz
    On a T = 1000/90 = 11,1111 ~ 11,11ms
    Le temps qu'il reste pour le code est t = 11,11 - 8 = 3,1ms

3/ A 120Hz
    On a T = 1000/120 = 8,33333 ~ 8,3ms
    Le temps qu'il reste pour le code est t = 8,3 - 8 = 0,3ms

Les nombres à rendre sont : 5,9ms à 72Hz / 3,1ms à 90Hz / 0,3ms à 120Hz
